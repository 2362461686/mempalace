# 记忆宫殿技术文档

## 什么是记忆宫殿？

记忆宫殿（Method of Loci）是一种古老的记忆术，起源于古希腊时期。
其核心原理是将需要记忆的信息与熟悉的空间位置关联起来，
利用人类大脑对空间信息的天生优势来增强记忆效果。

## MemPalace 项目架构

MemPalace 是一个本地优先的 AI 记忆系统，采用三层结构：

### 第一层：翼楼（Wings）
翼楼代表大的分类，例如人员、项目、主题等。
每个翼楼下面可以有多个房间。

### 第二层：房间（Rooms）
房间是按时间维度划分的记忆单元，
可以是一天、一次对话会话或一个主题。

### 第三层：抽屉（Drawers）
抽屉中存储的是完整的原文内容，不做任何总结或改写。
这是 MemPalace 最核心的设计原则：逐字存储。

## 搜索机制

MemPalace 使用混合搜索策略：
- BM25 关键词匹配（精确匹配）
- 向量语义搜索（语义理解）
- 两种结果通过加权融合得到最终排序

## 嵌入模型

支持多种嵌入模型：
- MiniLM（英文，384维，默认）
- EmbeddingGemma（100+语言多语言，384维）
- BGE（中文优化，512/768/1024维可选）

## 隐私设计

所有数据存储在本地，不需要任何 API 密钥。
MemPalace 完全离线运行，用户数据永远不会离开设备。
